How to use this tool

        

          

            
1. Start the backend: run uv run python tubelens_server.py in the project folder, and make sure Ollama is running (ollama serve).

            
2. Check "Use local server", paste a YouTube URL, click Fetch Info. Transcript fills automatically; add a YouTube Data API key above to also auto-fetch the description and comments.

          

          

            
3. Click Generate Report — no AI key needed with the default "Local (Ollama via server)" provider. Reports are saved to summaries/. Very long videos are processed automatically in parts.

            
4. Alternatives: use OpenAI/OpenRouter via "Call AI API directly" (bring your own key), or click Assemble Prompt to copy the prompt into any chat LLM. No server? Paste transcript and comments manually — everything still works.
